# LifeFlow v0.9

iPhone向けの個人用ToDo、年間目標、習慣記録アプリ。SwiftUI、iOS 16以降。

- ToDoの✓で達成、×で失敗を記録します。通常のToDoの失敗は翌営業日（月〜金）へ繰り越します。祝日の判定はありません。日は午前4時に切り替わります。
- カテゴリを「習慣」にすると、同じToDoの✓と×が日別記録に反映されます。休養は習慣の詳細から記録します。週の目標回数は1〜7回です。
- 年間目標の進捗率はサブタスクのチェック数から計算します。サブタスクから追加したToDoの達成と、目標側のチェックは独立しています。
- 未起動通知の初期時刻は21:00です。アプリがその日にアクティブになったときに当日分を取り消します。予約数は他の通知に応じて変わり、翌日から最長13日分です。予約期間を過ぎると、次回起動時まで予約を補充できません。

左上の「？」に使い方、歯車に通知、履歴、検索、カテゴリ管理、JSONバックアップがあります。

## 保存と更新

アプリはToDo、履歴、目標、習慣記録を端末内のJSONに保存します。v0.8以前の形式1〜4を形式5へ読み替えます。初回書き込み時に更新前の原本を保護付きで端末内に保存します。形式5のバックアップを復元するにはv0.9以降が必要です。通知設定は端末の環境設定に保存します。

## ビルド

macOSにXcodeとXcodeGenを用意し、リポジトリのルートから実行します。

```sh
bash scripts/build-unsigned.sh
```

スクリプトはコアのXCTestを実行し、Xcodeプロジェクトを生成して、署名なしで `artifacts/LifeFlow-unsigned.ipa` を作成します。GitHub Actionsの同名ワークフローからも実行できます。アップロードする成果物は未署名IPAだけです。端末へ導入する際は、利用する署名ツールで署名してください。

macOSのXCTest、iPhone向けビルド、上書き更新と通知の実機確認は、このソース準備版では未実施です。
